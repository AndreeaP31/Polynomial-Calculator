## Overview
**Polynomial Calculator** is a desktop Java application that allows users to perform operations on polynomials through a clean and interactive graphical interface. It supports arithmetic and calculus operations, offering real-time visual feedback.

## Features
- Addition and subtraction of polynomials
- Multiplication and division (quotient & remainder)
- Derivation and integration of polynomials
- Input validation with error messages
- Clear, reset, and backspace functionalities

## Technologies Used
- Java
- Java Swing (GUI)
- OOP principles for polynomial representation and logic

## How It Works
- Polynomials are entered as strings (e.g., `3x^2 + 2x - 5`).
- The program parses the input, creates polynomial objects, and performs operations based on the user's selection.
- Results are displayed immediately in the interface.

## Installation & Usage
1. Clone the repository:
```bash
git clone https://github.com/AndreeaP31/Polynomial-Calculator.git
```

2. Open the project in an IDE (e.g., IntelliJ, Eclipse).
3. Compile and run the application:
```bash
javac *.java
java Main
```
